# Cidad-o-Alertar-0.1
O Cidadão Alerta 0.1 é uma ferramenta para facilitar a comunicação entre cidadãos e as autoridades competentes. Concorda em usar a aplicação de forma responsável e apenas para fins legais. É estritamente proibido o envio de informações falsas, enganosas, maliciosas ou de trotes.
